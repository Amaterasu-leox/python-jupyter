# Python Jupyter - Example & Pratique 

Ce projet contient un notebook Jupyter illustrant l'utilisation des bases de Python, la création de graphiques et la gestion de fichiers.

## 📌 Contenu du Notebook

1. **Bases & Variables** : Affichage de texte et gestion des variables (`nom`, `age`).
2. **Opérations Mathématiques** : Additions, soustractions, multiplications et divisions.
3. **Visualisation de Données** : Création d'un diagramme en bâtons des langages de programmation avec `matplotlib`.
4. **Système & Fichiers** : Exploration des répertoires (`os.listdir()`) et lecture de fichiers texte (`mon_fichier.txt`).

## 🛠️ Prérequis

Pour exécuter le notebook localement, vous aurez besoin de : 
- Python 3.x
- Jupyter Notebook / JupyterLab
- La bibliothèque `matplotlib`

pip install matplotlib jupyter
